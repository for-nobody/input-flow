Microsoft runtime components
----------------------------

The Windows x64 portable package redistributes self-contained Microsoft .NET
and Microsoft Windows App SDK components under Microsoft's applicable
redistribution terms. The release packaging script copies the corresponding
license and third-party notice files from the pinned build/runtime inputs into
Licenses/DotNet/ and Licenses/NuGet/.

Microsoft Visual C++ Redistributable is an external system prerequisite. It is
not copied into the InputFlow package and is not removed with InputFlow.

This notice is a component inventory, not a replacement for the complete
license texts supplied in the Licenses directory.
