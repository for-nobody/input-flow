## 3. M7 进入条件

静态 WinUI 3 smoke 和视觉骨架可先建立，但将真实规则启用、暂停和保存接入 UI 前，应记录：

1. Windows 菜单/按钮 release 墓碑场景。
2. repeat 在 KeyChord、KeyMouseButton、Hold、HoldMouseButton 的成功、失败、暂停和队列满。
3. 前缀失败回放紧跟新物理输入的目标观察顺序。
4. 普通与提升权限窗口的 SendInput 完整/零/部分结果。
5. 持续打字/点击并查询 stats 的耗时、分位、样本数和 Hook 存活。
6. 左右修饰、扩展键、键盘布局、鼠标位置和已有物理修饰状态。
7. 正常退出等待墓碑释放的 2 秒内/外边界。

未执行项必须标为“未执行”，不能用单元测试或无输入 smoke 替代。

## 4. M7/M8 不变量

- agent 是唯一 Hook、规则验证、正式配置和热应用所有者。
- Named Pipe/UI 控制必须经过 Hook owner 的既有串行化边界，不能重新引入暂停超车。
- UI 周期读取诊断不得在 Hook 热路径持锁排序。
- 完整键盘扩展保留墓碑、repeat、timer、SendInput 诊断和原子配置语义。
- 鼠标 move 热路径只做无分配 O(1) 累计，不逐点日志或无界排队。
- F12 紧急旁路在设置断线、录制和配置错误时仍可用。
