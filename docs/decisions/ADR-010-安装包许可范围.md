# ADR-010：安装包许可范围

- 状态：提案
- 日期：2026-10-12
- 范围：Windows x64 安装包的程序目录
- 关联：ADR-009

## 背景

ADR-009 的便携 zip 随包携带 .NET 与 Windows App SDK，因此打包脚本把项目 MIT 许可证、
`THIRD-PARTY-NOTICES.txt`，以及每个锁定 Cargo、NuGet 和 .NET 输入的原始许可文件一并放入
`Licenses/`。安装包改为使用系统中的 Visual C++ 2015–2022 x64、.NET 10 共享框架和
Windows App Runtime 2.5.1。框架依赖发布不再把 .NET 运行库或 `Microsoft.WindowsAppRuntime.dll`
放进程序目录。设置工程只引用当前代码用到的 `Microsoft.WindowsAppSDK.WinUI` 2.3.9、
`Microsoft.WindowsAppSDK.Runtime` 2.5.1 和 `Microsoft.WindowsAppSDK.InteractiveExperiences` 2.1.9，
不再引用 Windows App SDK 总包，因此不携带 AI、机器学习、搜索和小组件。WinUI 包自身仍依赖
WebView2。许可只跟随本目录实际分发的程序。

## 决定

1. 已经发布的 v0.9.0 zip 不改。根目录 `THIRD-PARTY-NOTICES.txt` 继续描述那一份 zip。
   下次重新打包时，zip 与安装包使用同一组 Windows App SDK 引用。
2. 安装目录保留 `LICENSE.txt`。
3. 只保留编进 `inputflow-agent.exe` 的 Rust 库的许可正文：itoa、memchr、serde、serde_core、
   serde_json、zmij、windows-sys、windows-link。`MIT OR Apache-2.0` 与 `Unlicense OR MIT`
   只附 MIT 文本。
4. syn、quote、proc-macro2、serde_derive、unicode-ident 只在编译期使用，不进入最终可执行文件，
   不随安装包分发其许可。
5. 安装目录包含 Bootstrap，以及 WinUI、Foundation、Interactive Experiences 和 WebView2 的二进制。
   保留 `Microsoft.WindowsAppSDK.Runtime` 2.5.1 的 `license.txt` 与 `NOTICE.txt`，以及 WinUI、
   Foundation、Interactive Experiences、WebView2 的许可。终端用户须受不弱于 Windows App SDK
   协议的条款约束，且不移除其中的微软及供应商声明。不放入 AI、机器学习、搜索、小组件及其许可。
6. 不放入 .NET 运行库许可，也不放入目录中没有对应二进制的 NuGet 许可。不放入仅作索引的
   `THIRD-PARTY-NOTICES.txt`。

## 代价与后果

- 安装目录的 `Licenses/` 不能从 zip 整份拷贝，必须按当次程序目录里实际有的二进制重新确定。
- 若以后把某份运行库重新放进安装目录，必须同时加回该组件的许可和供应商声明。
- 根清单若改成安装包口径，已发布 zip 的第三方说明会失真。
