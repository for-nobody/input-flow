# InputFlow · Stage 6 触控板虚拟操作面板

**Codex 开发任务卡** · 阶段状态见[当前状态](../status/CURRENT_STATUS.md)，现场证据见[执行记录](../records/TOUCHPAD_STAGE_6_VIRTUAL_PANEL.md)

将 Stage 5 数字键盘并入一个「触控板虚拟操作面板」。用户可以直接使用数字、媒体、演示控制预设，也可以在自己触控板的等比例示意图上画区域、绑定动作、保存多套布局。Windows Agent 在 Settings 关闭后仍应独立工作。

**主验收场景**　从规则页打开「管理预设」，新建空白预设，再点「编辑画布」。在独立窗口沿左上至右下切出两块，分别绑定 A、B。点左上角「保存到草稿」，画布自动关闭，主窗口的小图出现分界线。用主窗口原有的保存操作应用后，关闭 Settings，在实体板两侧各点一次，记事本收到 `ab`。重开画布，移动斜边，让原属 B 的位置归入 A。依次完成两级保存，原位轻触应得到 `a`。

## 2. 用户入口、布局和动作

在现有实验性触控板总开关下，以「触控板虚拟操作面板」替代原数字键盘入口。开启功能并保存后，用户通过进入绑定开始运行。规则页沿用既有实验功能显隐和滚动行为。Stage 4「演示激光笔」有独立入口。面板内的「演示控制」用于翻页。

| 布局 | 首次提供的板面 | 输出约定 |
|---|---|---|
| 数字键盘 | 四行四列。前三行依次为 `7 8 9 ÷`、`4 5 6 ×`、`1 2 3 −`。底行是占两列的 `0`、`Enter`、`+` | 数字复用 Stage 5 修复路径。四则运算键分别交付加、减、乘、除。`Enter` 发送回车。核对计算器操作和文本目标实际收到的内容。普通规则中显式绑定的 `Numpad2` 等保留原键身份 |
| 媒体 | 两行三列，上排「上一首／播放暂停／下一首」，下排「音量减／静音／音量加」 | 复用已有媒体键和音量键。提交一次只触发一次 |
| 演示控制 | 左半板「上一页」、右半板「下一页」 | 默认使用应用可识别的上一页／下一页键，可改绑。在有焦点的放映窗口实测 |
| 自定义 | 新建空白布局，或复制现有布局，多套可同时保存 | 可命名并独立绑定切换键。区域至少支持单键、键盘组合及上述数字、运算、媒体动作。编辑器显示实际输出绑定 |

所有布局都能查看、改名、编辑区域、复制和删除，包括内置预设。用稳定 ID 引用布局、区域和绑定。删除「媒体」只释放它自己的切换键，其他布局不顺位重排。允许删到零套，重启仍为空，页面给出「新建自定义布局」「从预设添加」。恢复某项预设时创建独立布局并检查快捷键冲突。若主窗口保存应用时删掉正在运行的布局，则终止面板会话并丢弃候选与待发动作。

## 3. 预设管理与画布编辑

### 3.1 主窗口 · 管理预设

从「规则 → 触控板虚拟操作面板 → 管理预设」进入 Settings 主窗口内的独立页面。数字、媒体、演示控制和自定义预设共用以下流程。

| 位置 | 内容与操作 |
|---|---|
| 最右侧预设列表 | 显示所有预设，提供「新建自定义预设」「从预设添加」。选中高亮代表正在查看的预设，默认标记代表面板下次启动的目标。切换查看保留主草稿，运行态只随运行命令或正式配置应用而改变 |
| 中央详情区 | 显示所选预设名称、切换快捷键、默认状态，提供复制、重命名、删除、设为默认和「编辑画布」。复制生成独立 ID 和区域副本。复制区域动作，副本的预设切换键留空 |
| 中央小预览 | 只读，按设备比例显示当前预设的分区轮廓与留白。缩略图中省略区域名称、动作、绑定、工具及编辑手柄。切换预设或接收画布草稿后刷新。窄窗允许收起右栏，仍能访问预设列表和编辑入口 |

### 3.2 独立画布窗口 · 打开与保存

「编辑画布」打开独立的 WinUI 窗口。顶部左侧是**「保存到草稿」**，旁边提供**「撤销」「恢复」**。选择、矩形分割、直线分割和选区工具随画布显示，大触控板图占主要空间。管理页小图与画布用途不同，运行时的屏幕提示仍按第 5 节设置显示。

1. **打开。** 从主窗口当前草稿复制所选预设的可编辑内容，用预设 ID 标识编辑对象。重复打开同一预设时激活已有编辑窗口。即使主窗口切换了选中项，写回目标仍是最初打开的预设。
2. **编辑。** 拖动、切割、改绑和撤销仅改变窗口内的工作副本。主窗口小图继续显示已接收的主草稿。此阶段不写正式配置、不调用 Agent 应用，也不执行图中的动作。
3. **保存到草稿。** 校验后，一次性把本次编辑的板面几何和区域内容合回对应预设，保留主草稿中其他预设和其他字段的改动。成功后自动关闭画布并把焦点交回管理页，对应小图读回新轮廓。校验失败或目标已删除／同一板面有冲突时，窗口保留本次编辑，提示具体原因。若同时编辑了别的预设，写回不得因当前列表选项改变而误投。
4. **主窗口保存。** 用现有 Settings 保存入口持久化并应用完整草稿。主窗口放弃草稿沿用原配置。正式保存失败时沿用既有失败恢复，用户可以重新打开这份草稿继续修改。
5. **直接关窗。** 内容与打开时一致可直接关闭。有未保存改动时，关闭按钮或 Alt+F4 提供「保存到草稿／放弃更改／继续编辑」。同时关闭 Settings 时先处理编辑窗口的未保存改动，再按现有主草稿流程收尾。

### 3.3 设备比例、区域选择和绘制

以当前设备 HID 报告的有效感应面为基准，读取两轴可信物理跨度，按实际宽高比等比绘制，必要时在图旁显示毫米宽、高。复用现有 HID 换算。缺少可信物理尺寸时标注「示意比例」。设备缺失时可编辑已有布局。布局保存板面相对坐标，Windows DPI、窗口尺寸和系统光标位置不改变运行命中。

| 画布操作 | 行为 |
|---|---|
| 看图／悬停 | 大图在区域内显示名称、动作、绑定，例如「保存 · 发送快捷键 · Ctrl+S」。按区域可用空间折叠，悬停或键盘焦点可查看完整信息。标签随多边形裁切，避免盖住相邻区或落在凹口中 |
| 左键选择 | 选择工具下单击仅选中并高亮。编辑名称、动作和绑定由「编辑区域」或右键菜单进入，复用现有选择／录制控件。Ctrl+单击增减选区。选一个区域可分割，选中共享边段的区域可合并 |
| 删除 | 工具栏、区域菜单和画布聚焦时的 Delete 删除选区，位置释放为可重新规划的背景。文本框中 Delete 编辑文字，快捷键录制中由录制控件接收按键 |
| 矩形分割 | 可在任意位置拖出两个对角点。在未划分背景中创建矩形区域。分割已有选区时预览矩形内外及各自如何继承动作。新切出的块可保留为有轮廓的未绑定分区。对不支持的交叠给出明确预览，保留最后一次有效编辑 |
| 直线分割 | 指定范围为「整个板面」或「选中区域」，可横切、竖切、对角或任意角度分割。空板一刀可生成两个可绑定分区。预览切线和受影响轮廓，指出哪块继承原动作。保留未触及区域的绑定 |
| 合并／拖公共边 | 合并保留 L 形等真实轮廓，原动作不同时由用户选择继承项。公共边可直接拖动，两侧轮廓同步变化，含斜边及交点。使用独立的边界高亮和指针样式，区别于从区域内部开始的搬移 |

用同一份布局几何定义驱动小预览、大画布、运行提示及 Agent 命中。明确区分有轮廓但未绑定的分区、未划分的背景、边界窄缝。无效切割、越界、自交、零面积等给出就地反馈。合并后的内部接缝消失。Rust 与 C# 若分别计算几何，用相同布局和点集验证边、角、凹口、极值及无效形状。

### 3.4 拖放 · 互换、适配、自由移动

从区域内部按住鼠标左键拖动，触屏可长按后拖动。拖动开始时记下指针在源区域中的抓取点。以**释放时的指针落点**和拖动前的布局确定目标。松手前同时预览源、目标的最终状态，再一次性提交。运行中的实体板仍遵守第 5 节的抬手确认规则。

| 指针落点 | 松手后的工作副本 |
|---|---|
| 已有动作的分区 | 交换两区的全部内容，包括名称、动作和绑定，各自适配对方的轮廓。例如小矩形「播放」与大三角形「下一首」交换后，三角形整块播放，小矩形整块切歌 |
| 已划分、未绑定的空分区 | 源内容填入目标的整个轮廓，源位置成为可重新绑定、合并或删除的空位。目标形状和大小均按预览适配 |
| 未划分的背景 | 将源区域按抓取点的位移整体平移至落点，保持轮廓、尺寸和绑定。原位置释放为背景，周边未划分空间继续留白。按平移后的完整轮廓检查板界及与其他分区的碰撞，排除源区域自身。无效时显示冲突并取消本次移动 |
| 原位、分界窄缝、板外或 Esc 取消 | 结束预览，保留拖动前的布局。点击或取消的操作不会产生撤销记录 |

### 3.5 画布撤销与恢复

- 工具栏「撤销」与 `Ctrl+Z` 执行同一命令，「恢复」与 `Ctrl+Y` 执行同一命令。两端各自根据可执行状态启用。
- 一次完成的矩形／直线分割、合并、拖边、移动、交换、删除或区域属性修改各占一步。一次拖动中经过多帧预览仅记一步。撤销或恢复应完整还原相关几何和双方动作绑定。
- 撤销后提交新的有效编辑会清空原恢复分支。选中、悬停、失败或取消操作不会清空恢复分支。文本框获得焦点时优先使用其文本编辑行为，录制快捷键时由录制控件优先，避免一次组合键同时改变画布。
- 历史仅属于本次画布窗口。重新打开以当时的主草稿为新起点。草稿交接失败时保留工作副本和历史，供用户修正或撤销。

## 4. 模式与快捷键

| 当前状态 | 面板切换键（默认左 Alt+1／2／3） | 请求进入另一模式 |
|---|---|---|
| 普通状态 | 由前台或已配置的普通规则处理。面板内切换键只在面板运行时匹配 | 已启用且就绪的面板、激光笔可由各自进入键启动 |
| 面板活动 | 分别切至数字、媒体、演示。自定义布局可自行分配。切换后清除旧高亮、计时和待发动作，等旧接触全部离开再接收新 DOWN | 保持面板，显示不抢焦点的提示，写明如何退出当前面板再开启激光笔 |
| 激光笔活动 | 保留三种笔样式的切换，以及现有 Alt+4／5 和用户改绑 | 保持激光笔，提示先退出激光笔再开启面板 |

沿用进入／退出绑定编辑页。新配置可沿用双击 F9 进入、双击 F10 退出，默认进入数字布局。进入目标使用稳定 ID。若默认目标已删除且仍有布局，选取可用布局并在详情中显示当前默认项。用户可改面板进入／退出键与每套布局的切换键。清楚区分「面板如何进入」「运行时切到哪套布局」和「触碰某区域发什么键」。

按**可同时生效的作用域**校验冲突。面板与激光笔互斥，允许复用同一 Alt 组合。面板活动时，各布局的选择键同时有效，因此两个布局绑定同一组合时要报告重复。普通规则、全局入口及紧急旁路有歧义时，指出冲突对象并沿用现有可预期的匹配／回放行为。用户旧配置与新预设默认键冲突时保留旧键，新默认键可留空并可见地提示。调整校验、索引及实际 Hook 匹配三处。现有“另一模式活动时不可用”的判断还得能辨别明确的启动请求，才能发出互斥提示。Hook 只判定快捷键和派发轻量事件。通知展示、几何运算及 UI 绘制在对应工作线程完成。

活动时 Esc 退出并消费这次按放，幻灯片仍在放映。默认 F12 或用户配置的紧急旁路始终优先。切层或退出后，旧接触、排队输入及迟到的抬手均不能在新布局中触发。重复选择当前布局可视作无操作。

## 5. 运行契约与屏幕提示

- 复用现有后台 HID 订阅、设备归属、同一 contact ID 的明确抬手、焦点与修饰键复核。单指 DOWN 选区，提示可见时高亮。逐份处理报告。同区 UP 最多提交一次。移入另一区域后再返回仍取消。移入大片留白、无绑定区、物理按压、多指、丢失 UP 或设备切换均不输出。仅穿入内部分界窄缝时，沿用 Stage 5「回到原区可继续，在缝中抬手取消」的行为。
- 层之间使用同一个活动会话。Touch Click 在面板占用期间暂停自身的合成点击。在退出后按原配置恢复。复用现有对 Windows 单指原生轻点的只读检查，开启或状态未知时在可见位置说明不可输出的原因。保留外接鼠标正常操作，检查光标位置与键盘焦点分离的实机用例。
- 焦点改变、开始绑定录制、禁用功能、应用配置、设备断开、锁屏、休眠或 Agent 退出时，撤销受影响的接触和待发输出。按会话及布局版本在实际发送前复核，拒绝旧批次。注入数字、运算符或组合键时保留对外部已按住修饰键的保护。进入、切层、输出及退出均不得触发 Num Lock 切换。沿用软件输入标记、有界队列及失败处理。组合键若只插入一部分，按实际按下情况有界释放，避免重复整批或留下修饰键。日常日志沿用汇总计数和取消原因。
- 提示共四档：**始终显示、显示 2 秒、显示至首次成功输出、不显示**。新会话或实际切到新布局时重置提示。成功指 Agent 完成该动作所需的整批输出。候选高亮、取消、零或部分插入均不算。提示使用当前布局实际轮廓和区域标签，不截获点击或键盘焦点。由 Agent 会话计时，切层后旧定时器及旧动作完成通知不得隐藏新图。任意秒数／任意成功次数留作后续扩展，Stage 6 验收上述四档。

## 6. 分段实施与配置兼容

按当前 checkout 先定位每段的输入、输出及测试入口，再逐段实现和验证。首个可运行切片应尽早跑通两个三角形，随后扩展完整编辑交互。

| 阶段 | 编写代码 | 本段退出条件 |
|---|---|---|
| **6A 区域引擎** | 从固定 `DIGITS`／`Confirmed(u8)` 提取布局、区域 ID、动作、命中和接触确认。以直线切割产生的真实多边形支持内置及自定义布局 | 旧十键样本与触碰行为可复现。对角线、凹口、公共边、留白和可重复序列有确定测试 |

**配置迁移**　新装默认遵循现有实验开关策略。对已有 v7 数字键盘用户，迁移原启用状态、进入／退出绑定、提示策略，并生成保留原 3×4 空位、触点和窄缝的经典数字布局作为原入口目标。允许用户从预设添加新四则布局。迁移只做一次，区分“还没有布局字段”和“用户主动删空”。原有普通规则、激光笔和 Touch Click 设置随一次配置事务保留。更早版本沿仓库原有迁移链处理。Agent 重启后回到非活动态。

**配置应用**　复用现有草稿、校验、落盘、重连读回和备份／失败恢复逻辑。拒绝不可用绑定引用、非法几何及超出既有协议帧限制的文档时，保留可编辑草稿和上次有效配置。新 Settings 配旧 Agent 时按握手能力展示。旧客户端提交的模型不应无声清空新布局。对加载、编辑、发送、落盘失败及重开后的状态分别验证。

## 7. 测试与现场验收

从仓库根目录执行已有入口。完整 Windows 环境运行 `.\scripts\build-windows.ps1`。依赖已还原时可加 `-SkipRestore`。快速迭代可用 `cargo fmt --all -- --check`、`cargo test --workspace`、`cargo clippy --workspace --all-targets -- -D warnings`。改动共享 HID／探针路径时补跑 `cargo test --locked --manifest-path experiments/touchpad-probe/Cargo.toml`。记录完整 Windows 构建中的 C# 协议、Settings Core、WinUI Debug／Release 和本地化结果。
