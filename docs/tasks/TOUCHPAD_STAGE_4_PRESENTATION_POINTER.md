# InputFlow · Stage 4：触控板演示激光笔与通用同键双击

**文档类型**　产品说明与 Codex 开发任务卡　　**状态**　已实现，本机单屏核心流程通过，部分场景待实测
**适用位置**　`docs/tasks/TOUCHPAD_STAGE_4_PRESENTATION_POINTER.md`

执行证据见[触控板 Stage 4 验证记录](../records/TOUCHPAD_STAGE_4_PRESENTATION_POINTER.md)。

**用户验收场景**　我在笔记本上打开一份 PDF，把演示画面放到投影屏。双击左 Ctrl，投影上出现默认激光点。我切到蓝色笔迹圈出一个公式，再切到空心圆指向其中一项。临时切回鼠标后，我可以在笔记本上操作备注，投影上的圈仍然可见。回到激光笔时，光点回到公式旁。双击右 Ctrl 结束演示，光点和本次笔迹全部消失。关闭设置窗口后，这套操作仍由 Agent 提供。

以[触控板提案](../planning/InputFlow-Touchpad-Expansion-Proposal.md)第 4 节、第 15 节 Stage 4 和第 18 节 Experiment C 为基础。激活方式采用本卡确定的左右 Ctrl 双击。**4A 交付相对移动的完整演示流程，4B 加入绝对映射，并比较两种模式的实际手感。** 翻页手势、演示软件插件和 Stage 5 虚拟数字键盘另行规划。

## 1. 用户如何配置

1. 在「设置 → 实验功能」保留现有「触控板支持」总开关。总开关打开时显示子开关「演示激光笔」。新装和旧配置升级后，激光笔默认关闭。Touch Click 与激光笔可分别启用。
2. 两个激光笔相关开关的**草稿值**都打开时，规则列表立即出现唯一一张内置「演示激光笔」操作卡。沿用普通规则行及编辑入口，摘要显示开启键、关闭键和预设数。功能启停归设置页管理；卡片编辑绑定、样式和指针设置。隐藏卡片时保留已有配置。
3. 两页共享一个草稿。从设置页切到规则页、编好快捷键和预设后，只需点一次现有 **Validate and Save**。设备运行状态和实际快捷键以 Agent 确认的正式配置为准。保存前不占用新快捷键；保存失败保留草稿并指出具体字段；放弃编辑即可恢复正式配置。
4. 编辑器分为「运行快捷键」「样式预设」「显示与定位」。运行区列出开启、关闭、临时操作鼠标和立即清屏。预设列表每行显示默认单选项、真实外观预览、名称和绑定，选中后编辑参数。显示区提供目标屏幕与屏幕识别，单屏自动选择；4B 完成后提供「相对移动／绝对定位」。可用局部预览试颜色、线宽与背景对比。双语资源、键盘焦点和朗读名称沿用现有 WinUI 约定，隐藏卡片也须退出焦点和朗读顺序。

### 运行快捷键

| 操作 | 初始绑定或配置要求 | 触发行为 |
|---|---|---|
| 开启激光笔 | 左 Ctrl × 2，可改 | 从未演示进入，用保存的默认样式；重复开启保持当前工具、位置和笔迹 |
| 关闭激光笔 | 右 Ctrl × 2，可改 | 从指示、绘画或临时鼠标状态结束演示，清掉本次标记。会话中保留 Esc 作为快捷退出；消费该次完整按放，后续 Esc 交给前台应用 |
| 切换到某个样式 | 每个预设可编辑自己的绑定；仅有一个预设时切换键可留空 | 演示期间在最后光点位置切换样式。处于临时鼠标时可直接回到指定样式 |
| 临时操作鼠标／返回 | 可选绑定；再次触发返回 | 保存光点和当前样式，交还系统鼠标；返回时恢复上次样式 |
| 立即清屏 | 可选绑定，可留空 | 在演示和临时鼠标状态均可用，只清笔迹，保留会话、工具及两个位置。清屏时断开旧笔画，后续绘制从新线段开始 |

激光笔关闭时，样式、关闭、临时鼠标和清屏绑定对前台输入直通。会话中紧急旁路（默认 F12，遵循实际配置）优先于全部绑定。设置页开关保存为“开”仅表示允许以后启动，启动 Agent 或保存配置本身均不会开启演示。

## 2. 通用同键双击与已有触发方式

**同键双击是普通规则也能使用的新触发类型。** 即使触控板实验总开关关闭，用户仍可创建「A × 2 → 已有键盘动作」。激光笔的各项操作共用普通规则已支持的触发器、按键身份、录制控件、匹配和冲突校验，包括双键组合、已有的长按／键鼠类触发方式，以及新增的同键双击。首版沿用现有输入规模，双键组合最多两个键，同键双击只选一个键、次数固定为二。双击识别不应靠新建第二套键盘 Hook 或在两个组合键槽中填同一个键实现。

- **何时命中**　同一按键完成两次独立的按下和松开，在第二次松开时触发一次。分别记录单次按住上限、第一次 UP 到第二次 DOWN 的间隔上限、等于上限时的处理。使用可控单调时钟测试并在实机记录实际参数。保留逻辑键／物理键语义和左右修饰键区别。
- **何时放弃**　自动重复、长按、其他键或鼠标按钮介入时取消双击候选。左右 Ctrl 各点一次不能启动。独立轻点、系统组合、已配置的长按（例如长按左 Ctrl 复制）和键鼠操作仍各自生效。录制、暂停、前台目标变化和热应用作废旧候选，不能在新窗口补发动作。自身注入和回放不重新参加匹配。
- **单按与回放**　给 A 绑定双击后，单按 A 并等到超时，目标应收到一个 a；快速键入 AB 应得到 ab；快速双击 A 只执行一次绑定动作，目标不会先插入一个 a。按住 A 应保留正常长按或已绑定的长按语义。仅对确有活动绑定的前缀使用现有有界暂扣／回放机制，未命中的事件按原序仅交付一次。尤其检查 Ctrl+C 的原有按放顺序与可感知延迟。
- **冲突**　普通规则和激光笔在同一生效范围内共用冲突校验。重复绑定、与实际紧急旁路键冲突等错误应指出双方及字段。能以时序区分的短双击和既有长按要验证共存。演示未开启时，不因未生效的样式键拦截普通输入。快捷键录制期间也不能触发正在编辑的动作。

## 3. 样式、预设和笔迹

| 样式类型 | 可编辑参数 | 手指行为 |
|---|---|---|
| 空心圆 | sRGB 颜色、直径、圆环粗细 | 移动只指示，中心可见原内容 |
| 实心圆 | sRGB 颜色、直径 | 移动只指示 |
| 拖尾笔迹 | sRGB 颜色、线宽、保留方式、限时保留秒数 | 有效单指落下并移动就画，抬手断笔；下次落指另起一笔 |

每种样式共用 sRGB 调色盘、可输入的 `#RRGGBB` 和红、黄、绿、青、蓝、品红、黑、白等标准色块。预设支持新增、命名、编辑、删除，同一类型可以配置多份。**建议初始提供红色空心圆、黄色实心圆、蓝色拖尾**，红环为默认；可编辑的出厂样式键可先试 Alt+1／2／3，沿用正式冲突校验。单个预设自动作为默认。多个预设各有独立映射，必须恰有一个默认值；删除默认时让用户看到新的默认项，零预设的已启用配置不能保存。用稳定 ID 关联绑定和默认值，重命名与排序后映射应保持。临时操作鼠标在运行区绑定，不进入预设列表或默认样式选择。

- **限时保留**按每一段笔迹的绘制时刻独立计时。设为 3 秒，第 0 秒画的段在第 3 秒消失，第 2 秒画的段持续到第 5 秒。如果手指已经抬起或已切到鼠标，计时仍继续。数值校验只对限时模式生效。
- **保留到清屏**的笔迹在切换样式、应用窗口或临时操作鼠标时继续可见，直至清屏或会话结束。切换工具立即断笔，旧笔迹保留绘制时的颜色、宽度及寿命。清屏移除所有样式留下的笔迹，并作废旧的待绘制批次，避免下一帧把它们画回来。
- **持续绘制**用实际长笔画测渲染延迟与资源占用。按需重绘、回收已到期段；对保留到清屏的笔迹可合并几何或缓存已绘制内容。资源紧张时优先保留清屏和退出能力，记录具体限制，不能用隐含超时偷偷擦掉用户选择保留的笔迹。

## 4. 两个位置、两种移动方式

Agent 分别维护**最后操作系统鼠标的位置**和**最后激光点的位置**。演示悬浮层应置于目标画面上方、允许点击穿透、保持原应用焦点。关闭 WinUI 后，绘制、快捷键和退出仍由 Agent 负责。

| 转换 | 应记住和恢复什么 |
|---|---|
| 普通鼠标 → 开启演示 | 保存系统鼠标位置 A。首次进入相对模式时，建议让默认光点出现在所选屏幕中央 |
| 光点到达 B → 临时鼠标 | 结束当前笔画，记住 B 和工具，隐去光点，已有笔迹照常显示。把可操作的系统指针恢复到 A |
| 系统鼠标从 A 移到 C → 恢复演示 | 更新系统鼠标记忆为 C，光点先恢复到 B。等旧接触离开后才接受新 DOWN，绝不把 C 与 B 连线 |
| 再次临时操作／关闭 | 再次切回鼠标时回到 C。直接关闭演示同样交回最近的鼠标位置；从临时鼠标状态关闭则保留当时实际位置。退出同时清除本次光点和笔迹 |

**4A 相对移动。** 首次落指记录起点，之后以同一接触的位移推动光点。抬手只结束这段移动或画线，手指回到板中央重放也不会使光点跳走。把光点限制在目标显示器内；新接触、设备变化或多指介入应断开旧线。

**4B 绝对定位。** 以描述符给出的 X/Y 逻辑最小值和跨度分别归一化，将每轴的 0～1 映射到所选显示器对应方向的首末有效像素。使用目标屏的桌面原点，覆盖负坐标、非主屏及混合 DPI。落指左上／中央／右下对应屏幕相应位置，映射跳转不生成跨屏线段。从临时鼠标返回时先显示 B；下一个全新 DOWN 才定位到新绝对坐标并起笔。目标屏断开时建议结束当前演示，重新选择有效屏幕后由用户再开启。

**把 Windows 原生行为列入最早的实机实验。** Stage 3 已能在后台读到 HID 报告。只读报告本身不能证明系统箭头、原生轻点和物理鼠标已独立。分别观测系统箭头实际位置、焦点、意外点击／翻页和光点位置。演示指示或绘画时暂停 Touch Click 合成，临时鼠标及退出后恢复进入演示前的有效输入配置（含原本启用且仍合格的 Touch Click），恢复需等待新接触。原生轻点开与关分别测，激光笔绘制能力与 Stage 3 的点击输出条件单独判断。任何来源区分策略都应保留正常外接鼠标操作。若实机尚不能隔离某条路径，记录触发条件与受影响操作，保留可验证的部分，不静默改写 Windows 设置。

## 5. 给 Codex 的实现顺序

先核对当前 checkout、适用 ADR、[Stage 3 任务](TOUCHPAD_STAGE_3_TOUCH_CLICK_INTEGRATION.md)和[实机记录](../records/TOUCHPAD_STAGE_3_TOUCH_CLICK.md)。以下路径按随附的 Stage 3 快照给出。实际开工时在 `docs/records/TOUCHPAD_STAGE_4_PRESENTATION_POINTER.md` 记录基线、关键取舍、可复现命令和实测证据。依次完成下面的工作，遇到硬件缺口仍可继续实现和测试独立部分。

| 顺序 | 仓库入口与工作 | 本步交付 |
|---|---|---|
| 1 · 通用双击 | 从 `crates/inputflow-engine/src/{rules,matcher,pending}.rs`、`crates/inputflow-config/src/config.rs` 和 WinUI `Controls/KeyPicker` 入手。跟踪候选、定时、消费、回放和注入旁路；新增普通规则触发类型并接入现有编辑器 | 触控板实验关闭时，普通双击规则仍可新建、保存、重载、触发；单按及已有组合、长按通过回归 |
| 2 · 4A 相对指针 | 复用 `crates/inputflow-touchpad/` 的 HID 描述符和接触追踪、`crates/inputflow-windows/src/platform/touchpad.rs` 的后台订阅。当前 `Worker::refresh` 的订阅依赖观察模式或 Touch Click；调整为按实际使用者管理，确保仅开启激光笔也能用。Rust Agent 管理会话和 Win32 覆盖窗口，Hook 回调保持轻量 | 在目标屏上用相对模式移动单个光点；用早期实机实验验证 A、B、C 往返，以及 Esc、紧急旁路和异常退出能恢复操作 |
| 3 · 4A 配置与完整交互 | 串起 `crates/inputflow-{config,protocol,runtime}/`、`apps/inputflow-agent/src/ipc.rs`、`apps/settings-winui/`。复用 `DraftSession`、`ConfigSaveService`、`MainPage`、双语资源和规则编辑控件。补齐全部预设、快捷键、临时鼠标、清屏、状态读回和热应用 | 从同一草稿一次保存到 Agent，在关闭 Settings 的情况下完成相对模式全流程，覆盖失败恢复 |
| 4 · 4B 绝对定位 | 在相同会话、工具和覆盖层上增加绝对映射、目标显示器识别和 DPI 验证；用同一台设备、同一组目标对照相对模式 | 在目标屏完成角点、中心及两处不连续落指的验收，记录指向小目标的时间、偏差和主观手感 |

**配置与兼容。** 快照的正式 schema 是 v5；若基线仍是 v5，建议升 v6，保留 v1～v5 迁移、原键鼠规则顺序与启停、Touch Click 阈值和旁路键。持久化开关、触发器、样式 ID／默认 ID、绑定、目标屏和移动方式。活动会话、临时鼠标状态、两处位置和笔迹仅驻留内存。Named Pipe 握手公布能力，状态区分已配置、可启动、绘画／指示、临时鼠标、不可用及原因。新旧 Settings／Agent 配对时保护不能完整往返的配置。内置激光笔卡与内部绑定数量不能破坏 `ConfigSaveService` 对 `RuleCount` 与 `EnabledRuleCount` 的现有核对。

**启停与故障。** 关闭任一正式开关、紧急旁路、锁屏、休眠、负责输入的设备断开、Agent 退出时，结束会话并清除标记，撤销候选和待绘制操作。恢复或重启后回到普通操作；重新启用开关可恢复配置，但需要新触发才开始演示。进入录制或热替换时作废旧手势与快捷键候选。后台输入、覆盖层创建、显示器选择或保存失败应向 Settings 返回实际状态和原因。实现同一次清理可重复执行；避免依赖正常退出才恢复的全局光标替换。

## 6. 验收与交付

| 检查 | 操作与判定 |
|---|---|
| 通用触发 | 用可控时钟覆盖单按、双击、边界、超时、长按、自动重复、AB 顺序、Ctrl+C、左右 Ctrl 混用、录制和配置切换。目标窗口核对按放数量，已消费双击不产生额外字符 |
| WinUI 和配置 | 从旧配置开始，总开关关时无激光笔入口；两页连续修改后一次保存，失败能改、取消能还原。关闭功能后改一条普通规则，再开启，原有样式／绑定仍在。测一个和多个预设、删除默认项、重复绑定、双语资源、键盘操作和状态朗读 |
| 指示与笔迹 | 同一会话试空心圆、实心圆、限时和常驻拖尾。在 0 秒和 2 秒画两段、保留设为 3 秒，两段分别在约 3 秒和 5 秒消失。临时鼠标期间常驻线仍可见；清屏只清笔迹，关闭结束会话并清掉全部标记 |
| 两个位置与正常输入 | 在笔记本和投影屏完成 A → B → C 往返，包含连续两次切换、恢复后首次落指、鼠标状态关闭、原生轻点开／关、Touch Click 开／关和外接鼠标。确认不会连线、误点或改变操作窗口焦点；Esc 先退出激光笔，随后正常退出放映 |
| 映射与应用 | 比较相对／绝对模式指向同一行小字、图表中心和四角的效果。覆盖单屏、扩展屏、DPI、全屏幻灯片、浏览器和 PDF。用 Teams 或 Zoom 分别共享整个屏幕、单个窗口，在接收端核对可见性；按实际结果说明各方式支持范围 |
| 生命周期与成本 | 快速切换工具、清屏、停用、锁屏／睡眠、设备或目标屏移除、退出重启；检查残留光点、输入和资源。记录闲置／绘制时 CPU、长时间保留笔迹的内存增长，以及清屏后回收情况 |

在 Windows 宿主机按[构建指南](../guides/BUILD_WINDOWS.md)运行 `scripts/build-windows.ps1`（覆盖 Rust workspace、WinUI Debug／Release、Core／Protocol 与本地化）。独立探针另执行 `cargo test --locked --manifest-path experiments/touchpad-probe/Cargo.toml`。实际运行后记录命令、结果、设备、显示器布局、缩放、应用与限制。用户只需完成需要真实手指、投影或会议接收端的操作，Codex 负责构建、准备复测步骤和整理证据。
