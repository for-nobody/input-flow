# InputFlow v0.9.0 发布说明

> 发布类型：Windows x64 公开测试版（Pre-release）
>
> 标签：`v0.9.0`

InputFlow v0.9.0 是首个公开测试版本。它提供由 Rust 常驻 Agent 驱动的全局键鼠组合规则，以及按需
启动的 WinUI 3 设置程序。首版已完成发布前短时输入、恢复、分发和生命周期验收；24／72 小时长时间
运行验收安排在发布后的 G-POST，因此本版不宣称已经证明长期稳定。

## 下载与校验

下载 `InputFlow-0.9.0-win-x64.zip` 和 `SHA256SUMS.txt`，核对 SHA-256 后将 zip 完整解压到普通用户
可写目录。不要只复制两个 EXE；DLL、PRI、XBF、许可证和其他资源必须保持完整。

本包携带 .NET 10 与 Windows App SDK 2.5.1 运行组件，但系统必须安装 Microsoft Visual C++
Redistributable 2015–2022 x64。发布包未签名；如 Windows 显示来源或信誉提醒，请核对校验和，不要
关闭系统保护。

## 主要能力

- KeyChord、Key+MouseButton、Hold 和 Hold+MouseButton 触发器。
- 键盘激活的鼠标左／右／上／下方向规则；鼠标轨迹始终直通，每次按住周期最多触发一次。
- logical／physical 键身份、完整具名键、scan-code 回放和 Schema v1～v4 确定迁移。
- Agent 权威配置校验、原子保存、恢复、规则启停、暂停和运行时热替换。
- 版本化、有限帧、当前用户 ACL 的 Named Pipe；WinUI 规则编辑、录制、诊断和保存核对。
- 托盘控制、F12 紧急暂停、Agent／Settings 单实例，以及默认关闭的当前用户登录自启动脚本。

## 首次运行

1. 安装或确认已安装 Visual C++ Redistributable 2015–2022 x64。
2. 完整解压发布包并运行 `inputflow-agent.exe`。
3. 双击托盘图标或选择 **Open Settings**。
4. 创建并保存规则；首次启动没有默认启用规则，不会主动拦截输入。

完整的自启动、升级、移除、配置位置和故障反馈说明见包内 `README.md`。

## 已知限制

- 仅发布 Windows x64 便携目录包；没有安装器、MSIX、自动更新或商业签名。
- 非提升 Agent 受 UIPI 限制，不能保证向提升窗口注入动作；输出还受焦点和当前修饰状态影响。
- 强制结束进程不能保证恢复已经暂扣的历史输入；正常退出最多等待两秒排空已消费释放。
- 多屏／跨 DPI 热插拔、部分特殊键硬件、中文 Narrator 实际语音、partial `SendInput` 和睡眠／唤醒
  仍缺少完整实机覆盖。
- 发布前样本出现过 stats 查询调度尖峰，但 Hook callback 与输出继续正常；发布后长测会继续观察。
- 本版尚未完成 24／72 小时长测，定位为公开测试版本。

## 升级与移除

升级时先正常退出旧 Agent，将新包完整解压到新目录，保留 `%LOCALAPPDATA%\InputFlow`，再从新目录
更新自启动入口并核对配置。不要在运行中逐文件覆盖旧目录。移除时先关闭 Settings、正常退出 Agent、
禁用自启动，再删除程序目录；默认保留用户数据，也不要删除共享 Visual C++ Redistributable。
