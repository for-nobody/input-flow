2026-11-20（Australia/Brisbane）。基线为 Stage 5 后的 `45bb281`。验收使用独立的配置、界面偏好和 Agent 实例。[任务卡](../tasks/FIX_RULES_SCROLL_AND_TRAY_SETTINGS.md)

## A · 规则页滚动

修复前，在 200% 显示缩放的 Windows 桌面上，用 35 条普通规则以及同时启用触控板实验功能、激光笔和数字键盘的配置打开 Settings。约 539 × 355 的逻辑窗口下，规则区只露出第一张卡片上缘。在该区域滚动鼠标滚轮，页面未移动，第一条规则不可见。

修复后，三张实验卡片和空状态进入 `RulesList.Header`，由列表自己的 `ScrollViewer` 接收滚动。列表从父级星号行取得有限高度，继续使用 WinUI 默认的虚拟化面板。标题、筛选和保存操作保留在滚动区之外。短窗口压缩说明和正常连接提示，连接异常仍展示详情。激光笔及规则编辑保留独立滚动和原有宽窄布局。

## B · 托盘打开 Settings

修复前，运行中的开发 Agent PID 33056 位于 `target\release\inputflow-agent.exe`。现有日志多次记录 `open_settings: settings executable is unavailable`，目标均为其同目录的 `InputFlow.Settings.exe`。现场核对确认该文件缺失，WinUI 项目的开发输出中存在该文件。本次定位到的故障条件是开发目录直接启动 Agent；便携目录的默认解析以 Agent 自身位置为准。

新增联合开发入口 `scripts\run-windows.ps1`，由 MSBuild 定位所选构建配置，把 Settings 绝对路径传给首个 Agent。Agent 使用 Settings 所在目录启动子进程，记录路径、工作目录、PID 和三秒内的退出状态。缺文件、创建进程失败和异常早退时会给用户提示。Settings 按原窗口的 Win32 属性定位已有实例，最小化时请求恢复；Windows 拒绝切到前台时请求闪烁任务栏并留日志。[开发指南](../guides/BUILD_WINDOWS.md)

| 修复后试验 | Agent → Settings PID | 结果 |
| --- | --- | --- |
| 分目录开发构建，传入 WinUI Release 绝对路径，从测试数据目录启动 | 21960 → 34424 | 窗口创建，Settings 通过真实 IPC 读取配置和保存。日志记录正确路径和实际工作目录，Pause/Resume 均成功。 |
| 自包含便携目录 `便携 测试`，从其他工作目录启动并使用同目录默认解析 | 32096 → 29292 | 读取到 Settings 窗口标题和有效句柄，日志中的工作目录为应用所在目录。 |
| 传入缺失的 `missing.exe` | 35816 → 无 | 日志记录绝对路径，观察到标题为 `InputFlow - Open Settings` 的原生错误窗口。其间 Pause/Resume 正常，Agent 到预定截止时间正常退出。 |
| 原窗口最小化且保存新显示语言后，直接启动第二实例 | 37668 → 37696 / 18812 | PID 37696 仍显示英文标题，窗口由最小化恢复，未保存的数字键盘编辑仍在。命令执行桌面拒绝切前台，第二实例以 11 退出，触发任务栏闪烁请求。 |

托盘试验从隔离 Agent 的同一 `OpenSettings` 事件分支进行。命令执行桌面的通知区域返回 `Shell_NotifyIconW(NIM_ADD)` 失败，任务栏右键菜单、图标双击及实际前台切换待在交互桌面复验。运行中的日常 Agent 触发了联合入口的防重复检查，PID 33056 保持运行。
