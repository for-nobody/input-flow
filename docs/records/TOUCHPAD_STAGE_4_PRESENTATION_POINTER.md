# 触控板 Stage 4 · 演示激光笔记录

2026-11-19（Australia/Brisbane）。开发基线 `c5497a8`，正式配置 Schema v5。沿用 [Stage 3](TOUCHPAD_STAGE_3_TOUCH_CLICK.md) 的后台 HID、输入标记和旁路。Stage 3 的任务卡验收标记是既有工作树改动。

## 实现基线

- 同键双击复用现有 Hook、Matcher、有界 FIFO 和按键身份。单次按住上限 180 ms，两次之间上限 270 ms，等于上限可用。第一下未命中按原序回放。用单调时钟分别覆盖普通长按和系统组合。
- 演示把屏幕坐标和绘制留在 Agent 的触控板窗口线程。配置、启停和普通规则共用持久配置事务。会话持有两处位置、当前预设和笔迹。
- 先验证 HID 独立光点和目标屏定位，再用实际操作分开判定 Windows 原生鼠标与点击。保留外接鼠标直通。单屏、扩展屏、混合 DPI 和会议共享结果分别记录。

## 4A · 单屏早期实机观察

在同一台 ASUS Zenbook 的隔离配置启动 Agent，实验总开关和演示开关开启，Touch Click 关闭，Settings 已关闭。只识别到单一主屏 `DISPLAY1`，物理像素 2880×1800，桌面原点 (0, 0)。本机桌面 `AppliedDPI=192`（200%），Agent 的覆盖层线程以 Per-Monitor V2 坐标工作。Windows 单指轻点读回 `TapsEnabled=0xffffffff`（开启）。

操作者在记事本前台快速按放左 Ctrl 两次，确认红色空心圆出现。单指滑动及抬手后换位置落指均可连续定位。操作者同时看见 Windows 鼠标箭头随触控板移动。这一来源边界影响原生轻点和可能的前台交互。当前接入保留原生输入，应用继续收到 Windows 自身的鼠标行为。

状态读回保存的起始鼠标位置为 (1608, 1066)，观测时光点为 (1629, 565)。到该次读回共渲染 1,020 帧，最大单帧提交耗时 14.343 ms。Agent 进程工作集约 55.8 MiB，私有字节约 22.3 MiB。以上包含启动窗口及其他输入处理开销。触控板后台报告为 54,093 份，Touch Click 的合成请求与插入均为 0。

覆盖层单独冒烟在交互桌面执行成功，创建、脏矩形重绘及关闭全过程保持同一个前台窗口。参见 [Win32 分层窗口](https://learn.microsoft.com/en-us/windows/win32/winmsg/window-features)和[局部更新参数](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-updatelayeredwindowinfo)。

初次单独复测临时鼠标时，操作者确认蓝线与小光点同时消失。切换前为 `drawing`，常驻蓝线 789 段。切换后 IPC 报告 `unavailable / paused`，日志记录 `queue_overflow`、16 个暂扣事件成功回放和会话结束。修复后，仅有演示绑定的组合前缀在队列满时回放并结束该候选，Agent 继续运行。针对长按修饰键导致重复输入的回归测试覆盖回放顺序和下一次 Alt+4 命中。由于正式日志未记录逐键事件，此处无法确认填满队列的具体键序列。复测时重启了已旁路的隔离 Agent 并确认启动恢复。

修复版逐项复测时，操作者再次看到蓝线。IPC 在切换前读取到 485 段、光点 B=(2255, 1076)、已保存的鼠标位置 A=(1419, 1162)。Alt+4 之后进入 `mouse`，B 和 485 段笔迹均保存，系统箭头随后移动至 C=(1009, 966)。第二次 Alt+4 在切换当下仍记录 485 段，鼠标位置更新为 C。操作者确认临时期间蓝线一直可见，返回时光点回到原蓝线末端。返回后读回的光点和笔迹计数已包含后续接触的移动。

操作者切回红环后按 Alt+5，确认旧线消失、红环保留。IPC 为 `pointing / red-ring`，笔迹 0 段。右 Ctrl 双击后读回 `ready`，无光点、无笔迹，日志记录 895 帧，最大单帧提交耗时 14.634 ms。

## 4B · 绝对映射

本机描述符的 X 逻辑范围为 `0..3996`、Y 为 `0..2242`。单屏映射端点为物理像素 `(0, 0)` 与 `(2879, 1799)`。单元测试覆盖非零 HID 最小值、端点截断、显示器局部坐标，以及两处不连续落指的画线边界。实际落指及相对模式对照以实机读回为准。透过 Windows 读取的实际原始范围见[Stage 1B 记录](TOUCHPAD_STAGE_1B_PROBE.md)。

在正式 WinUI 规则页进入内置卡，选中绝对定位。界面先显示草稿未保存，点击一次验证并保存后，界面显示已验证、保存、应用及读回。磁盘及 Named Pipe 均返回 schema v6、`movement: absolute`、无普通规则。关闭 Settings 后在记事本前台用左 Ctrl 双击启动。三次落指的 IPC 采样如下，间隔约 380 ms，屏幕坐标用物理像素表示。

| 触控板位置 | 首个记录的光点 | 保持期间的光点范围 | 系统箭头首个样本 |
|---|---|---|---|
| 左上 | (163, 84) | X 163–170，Y 82–94 | (2183, 1012) |
| 中央 | (1487, 757) | X 1483–1487，Y 757–765 | (2186, 1016) |
| 右下 | (2744, 1744) | X 2742–2746，Y 1743–1745 | (2185, 1021) |

首次显示在屏幕中心 (1440, 900)，每次新落指直接更新为对应的屏幕区域。三个开始样本均为 `pointing / red-ring`，0 段笔迹。箭头在这些落指样本中保持在原区域，后续滑动仍能推动原生箭头。

蓝笔实际画了两段独立笔迹。左上段最后采到 (280, 102)，笔迹累计 217 段；右下重新落指后首个样本为 (2806, 1574)，随后计数增至 444 段。操作者确认两组笔迹之间没有跨屏连线。按 F12 后光点和笔迹消失，IPC 为 `unavailable / paused`，清零笔迹。日志记录这一会话共 458 帧，最大单帧提交 14.284 ms。画线后 Agent 进程工作集 59.1 MiB、私有字节 22.7 MiB。该时点的触控板报告为 8,131 份，Touch Click 合成请求和插入均为 0。

再次按 F12 恢复拦截，日志中直到新的左 Ctrl 双击才开启新会话。随后按 Esc 结束该会话，IPC 回到 `ready`，无活动光点或笔迹。

## 普通同键双击

在隔离配置的 Settings 页关闭触控板实验总开关。未保存即切到规则页，Touch Click 和激光笔卡都隐藏，同键双击仍可选。新建普通规则 `A × 2 → C` 后只点击一次验证并保存。读回为 schema v6、普通规则数 1，触控板实验已关闭，隐藏的激光笔配置仍保存原开关、绝对定位及三个预设。点击重新载入后，Settings 显示完成，普通规则仍为 `A × 2 → C`。

关闭 Settings 后，操作者用英文输入法做单按 A、快速按 A、B、快速双按 A。目标记事本的实测行确认为 `a ab c`。日志中两次双击命中对应的输出批次均为 `inserted=2 / requested=2 / Complete`，普通输入的回放批次也完整插入。测试后暂停了隔离 Agent 的输入拦截，进程到期正常退出。退出统计为 14 批输出，失败和丢弃均为 0，Hook 与日志线程均正常关闭。

## 单屏复现

在独立配置上启动 Agent。从旧配置开始时，进入「设置 → 实验功能」，开启「触控板支持」和「演示激光笔」。到规则页编辑内置卡，选择目标显示器和定位模式，再点一次「验证并保存」。可关闭 Settings，在记事本用左右 Ctrl 双击分别开启、结束演示。默认左 Alt+1／2／3 切换红环、黄点、蓝色常驻笔迹，左 Alt+4 切换临时鼠标，左 Alt+5 清屏。Esc 和现有紧急旁路也能结束会话。

## 实机覆盖边界

- 本轮使用内置触控板、Windows 原生轻点开启、Touch Click 关闭和记事本。原生箭头仍随触控板滑动，原生轻点路径仍由 Windows 处理。异常点击或翻页、原生轻点关闭、Touch Click 启用时的切换，以及外接鼠标仍待分别实测。验收前后读取到相同的原生轻点设置。
- 绝对落点与相对重落均有单屏证据。小目标用时与偏差、扩展屏负坐标和混合 DPI、投影或全屏放映、浏览器／PDF，以及 Teams／Zoom 的整屏和单窗接收端结果仍待实测。
- 限时线段单独到期有确定性测试。黄点及限时实画、显示器或输入设备断开、锁屏／睡眠、长时绘画的 CPU 和内存趋势，以及正式设置的冲突／取消和朗读仍待物理或人工验证。常驻笔迹最多 16,384 段，覆盖层缓冲上限 16,777,216 像素。满额时保留已有线段，Agent 仍可清屏和退出。
