# 触控板 Stage 2 · Touch Click 实验记录

2026-11-19（Australia/Brisbane）。宿主机为 ASUS Zenbook 14 UX3405MA，Windows x64 build `26200.9974`，触控板 `093A:300D`。
工作树基线为 `1388640`，独立探针 `0.3.0` 用于 2A，`0.3.1` 用于随后构建的 2B。
设备归因、描述符解析和单指生命周期沿用 [Stage 1B 实测记录](TOUCHPAD_STAGE_1B_PROBE.md)。

## 参数与构建

短触上限为 **400 ms**（含边界），长触门槛为 **500 ms**，两者之间先保持无点击意图。
移动阈值为 **3.0 mm**，仅在全程距起点的最大欧氏距离首次超过阈值时取消，回到起点也保持取消。
描述符给出 X `0..3996`、Y `0..2242`，物理跨度分别为 `1269`、`712`，单位为 SI 线性长度
（厘米）、指数 `−2`。因此每个坐标差分别乘 `126.9/3996`、`71.2/2242` 换算到毫米。
两轴无法可靠换算时的备用阈值为 `0.025`，单位为两轴逻辑跨度分别归一化后的欧氏距离，本机未使用备用值。

```powershell
cargo run --locked --manifest-path .\experiments\touchpad-probe\Cargo.toml
```

`1`～`7` 保留 Stage 1 的计数和接触采样。默认 `OBSERVE` 模式只显示手势意图并记录测试区实际收到的
Windows 消息。`Q/W/E/R/T/Y/U/I` 分别选择左侧短触、右侧短触、长触、移动、双触、物理按压及拖动、
双指和混合样本。`Enter` 结束当前样本，`Esc` 关闭。`+/-` 调整下一次接触的毫米阈值和备用归一化阈值，
也可用 `--short-ms`、`--hold-ms`、`--movement-mm` 和 `--movement` 设置启动参数。

2A 的离线 Windows 构建、格式检查、严格 Clippy 和 10 项单测通过。单测包括边界、同刻取消、折返、连续短触、
迟到或重复定时事件、ID 重用，以及长触触发后再移动或按压。2B 的 Windows 构建、严格 Clippy 和 12 项单测
通过，新增完整、零写入及部分写入后单次释放的确定性验证。这些测试未向桌面发送鼠标输入。

## 2B 当前边界

`0.3.1` 已加入目标区命中诊断和显式输出。`F6` 只补右键，`F7` 由探针产生左键和右键。
进入任一模式前须在该会话观察到物理按压和释放，指针须在前台测试区内，且所有手指已离开触控板。
离开测试区、失焦、设备移除或手动停用会撤销输出。按钮按下和抬起使用成对的 `SendInput`，目标通过
消息额外标记关联合成事件，并分别记录意图、插入数、目标收到的按钮消息和软件观测延迟。

启动 2B 桌面验证时，桌面操作因物理 `Esc` 停止。没有开始 2B 的目标内原生复验，未选定点击来源或开启合成输出。
目标点击、软件延迟、误右键率、双击、按住拖动和操作者手感仍待实机验收。原生设置未切换，因此无需复原。

## 2B 本机前台实测补录

2026-11-19（Australia/Brisbane）。使用现有 `0.3.1` 可执行文件，在同一台 ASUS Zenbook 上保持前台
Raw Input，实测参数仍为短触上限 **400 ms**、长触门槛 **500 ms**、移动阈值 **3.0 mm**。全程沿用原生设置。
会话日志为 `experiments/touchpad-probe/target/debug/touchpad-probe-16992-1795034769118.log`。

### 目标命中、原生基线与模式选择

先在只读模式确认 `target_inside=true`。一次框内物理按压和松开同时记录到 HID Button 两个边沿，目标实际收到
一组未标记左键按放，并产生 32 个字符的选区。读到这对消息后才用轻触判断原生点击来源。

首次选择模式时，命中文字框的 2 次左侧短触、5 次右侧短触和 8 次长触均未使目标收到按钮消息。另一个仍为
只读的复测补充了短触样本。两批 `Q/W` 合计 23 次框内短触，目标仍收到 0 条按钮消息，因此先选 `F7`。
合成输出开启后，`E` 组出现了持续 209、210 ms 的两次短触和两组未标记左键。其中第一次触发
`button_or_token_guard`，`F7` 自动退回观察模式。随后改用 `F6` 验证只补右键。原生左键不能依据先前的
零消息基线视为关闭。

### 识别意图、合成输入与目标送达

|---|---|---|---|

| `F7` 首轮 `E` | 三次在 241、209、210 ms 抬手，均为短触 | 第一次左键插入 2/2，第二次被保护拦截并停用，第三次为观察模式 | 1 组带标记左键按放和 2 组未标记左键按放，0 右键 |
| `F6` 最终三次足时长触 | 接触持续 1126、956、785 ms，均在抬手前判定长触 | 3 次均插入 2/2 | 3 组带标记的右键按放，每次在抬手前送达，各 0 额外左键 |

| 重新开启 `F7` 后的两组快速双触 | 4 次均识别为短触，第一次触发保护停用 | 0 次调用 | 两组均收到未标记双击。每组为普通左键按下、抬起、双击按下、抬起 |

左右短触按板面起始坐标复核，左侧 X 为 `387..616`，右侧为 `3573..3619`。短触 UP 到 `F7` 目标左键按下
为 **5.373～12.096 ms**。500 ms 门槛到 `F6` 目标右键按下为 **11.627～31.174 ms**，为软件观测值。
`F6` 长触组在最后三次之前另有 4 次短触及 1 次在 469 ms 抬起的空档样本，两次短触收到未标记左键，已从足时
长触的分母中单列。另一次观察组在 515 ms 抬手时计时尚未执行，记录 `timer_late_after_up`，未补发右键。

折返样本最远达到 **10.826 mm**，抬手时净位移 **0.810 mm**，持续 **2201 ms**，仍保持取消。两种模式合计
13 次实际 `SendInput` 调用均插入 2/2，26 条带标记按钮消息全部在文字框按放配对。另有两次被保护拦截，
未调用 `SendInput`。在 19 次非预期右击试次中实际误右键为 **0/19**，分母为 9 次左右短触、3 次平移或折返、
1 次拖选、1 次滚动、4 组双触和 1 次出框。测试没有观测到带标记与未标记按钮在同一次接触中重复送达。

**验收结论**　已验证左右侧短触的合成左键、足时长触的合成右键、折返取消和目标区停用。完整点击模式未通过。
`F6` 下两组快速双触均无左键。`F7` 两次保护停用时，目标均在同期收到未标记左键。当前原生设置和这些参数下，
尚无一种连续可用的模式。独立的失焦、物理右键及手感复验未完成。会话正常退出，读取 5,714 份报告，读取错误为 0。

## 2B F7 专项复测

2026-11-19（Australia/Brisbane）。同一台 ASUS Zenbook、现有 `0.3.1` 可执行文件与原 Windows 设置。继续使用前台 Raw Input，
短触上限 **400 ms**、长触门槛 **500 ms**、移动阈值 **3.0 mm**。本轮只启用 `F7`。会话日志为
`experiments/touchpad-probe/target/debug/touchpad-probe-25408-1795046495710.log`。

先确认 `target_inside=true`。观察模式下一次物理按放记录到 HID Button 的按下和释放边沿，文字框收到一组未标记左键按放。
随后在同一文字框内开启 `F7`，以实际采到的接触为分母。
